Présentation de Booki

Booki est la première page statique d’un site d’hébergement en ligne. Elle sert de page d’accueil pour permettre aux utilisateurs de découvrir le concept et d’interagir avec certaines fonctionnalités de base.

Fonctionnalités de la page
Effets de survol (hover) : les éléments interactifs changent de style lorsqu’on passe la souris dessus.
Focus sur les boutons : modification de la couleur des boutons lors de la sélection.
Navigation par ancrage : le focus sur un bouton permet de se déplacer directement vers une zone spécifique de la page en un clic.
Formulaire de recherche : un formulaire interactif qui illustre comment un utilisateur pourrait rechercher un logement.
Technologies utilisées
HTML5 pour la structure de la page
CSS3 pour le design, les effets hover et focus, et la mise en page responsive
