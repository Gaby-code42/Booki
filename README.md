# Booki

Page d'accueil d'une agence de réservation d'hébergements, intégrée en HTML et
CSS à partir d'une maquette Figma. C'est un projet de la formation Intégrateur
web d'OpenClassrooms.

## Ce qui a été réalisé

- **Une intégration fidèle à la maquette** : mise en page, couleurs, typographie
  et espacements.
- **Le responsive** : trois points de rupture (mobile, tablette, desktop) gérés
  avec des media queries.
- **Les interactions** : survol et focus sur les éléments cliquables, et
  navigation par ancres vers les sections de la page.
- **Le formulaire de recherche** : un champ de destination et des filtres
  (budget, ambiance, famille…).
- **Du code sans framework** : HTML sémantique, CSS natif, Flexbox.

## Stack

HTML5 · CSS3 (Flexbox, media queries)

## Lancer le projet

Aucune installation n'est nécessaire : il suffit d'ouvrir `index.html` dans un
navigateur.

```bash
git clone https://github.com/Gaby-code42/Booki.git
cd Booki
# puis ouvrir index.html
```
